최소 구한다.

오래 걸리는 걸 빨리 심어야 한다.

a1 <= a2 <= a3 <= .. <= an라 하고,
1 <= 2 <= 3 <= ... <= n : b[n]이므로
an+n, a[n-1]+n-1, a[n-2]+n-2, ..., a[1]+1이라 하는 게 최선이다.
왜냐면, i < j에 대해
b[i] < b[j]라 하자.
이때는 a[i]+b[i], a[j]+b[j]걸리니까, a[j]+b[j] 걸린다.
그런데 max(a[i]+b[j], a[j]+b[i]) <= a[j]+b[j]이므로, 바꾸는 게 이득이다.
