최솟값이랑 최댓값 저장하는 pq만든다
minpq, maxpq
최대-최소 <=1이될 때까지 반복한다.

TLE 뜬다.
O(m * nlogn)이니 당연한가
시복 파악하자.

전체 개수 m
m = na+r(0 <= r < n)
a = m / n
r = m % n
r개는 a+1, n-r개는 a로 만들어야 함

크기 순으로 정렬해서
다 더하고
2로 나누자.


-- 증명
A[1]>=A[2], ...>=A[n]라 하자.
b[i] : (a+1) or a, r개는 a+1, (n-r)개는 a

1 <= i < j <= n에 대해
b[i]=a < b[j]=a+1라 가정하자.
c1 = |A[i]-b[i]|+|A[j]-b[j]|
= |A[i]-a|+|A[j]-a-1|
c2 = |A[i]-a-1|+|A[j]-a|
i) A[j] >= a+1
c1 = A[i]-a+A[j]-a-1
 = c2 = A[i]-a-1+A[j]-A
ii) A[i] >= a+1, A[j] <= a
c1 = A[i]-a+a+1-A[j]
>= c2 = A[i]-a-1+a-A[j]
iii) A[i] <= a
c1 = a-A[i]+a+1-A[j]
 = c2 = a+1-A[i]+a-a[j]

세 상황 모두에서, c1>=c2이다. 

-- 회고
문제를 꼼꼼이 읽자. 인근 차가 1이하인줄 알았다.
시복 파악하자.

내 증명은 차이가 1인 거에 의존해서 2이상 일때는 안되는 줄 알았는데,
재배열 부등식으로 차이가 2이상일 때도 같은 그리디를 쓸 수 있다고 한다.
